# LBA_Restaurant_Engine

> **Simulador profesional de operaciones de restaurante** — editor 2D + motor de simulación determinista de eventos discretos. Código abierto, gratuito, ejecutable en local.

Este repositorio está gobernado por una **guía maestra de desarrollo** que se conserva íntegra en [`docs/guia/`](docs/guia/README.md) para que las instrucciones nunca se pierdan y cualquier agente o persona pueda seguirlas siempre.

- 📜 Prompt maestro del agente: [`docs/guia/00_PROMPT_MAESTRO_CODEX.md`](docs/guia/00_PROMPT_MAESTRO_CODEX.md)
- 🏗️ Arquitectura y estructura: [`docs/guia/01_ARQUITECTURA_Y_ESTRUCTURA.md`](docs/guia/01_ARQUITECTURA_Y_ESTRUCTURA.md)
- 📋 Fases del proyecto (00 → 11): [`docs/guia/FASES/`](docs/guia/FASES/README.md)
- 🧪 CI, logs y evidencias: [`docs/guia/03_GITHUB_ACTIONS_LOGS_EVIDENCIAS.md`](docs/guia/03_GITHUB_ACTIONS_LOGS_EVIDENCIAS.md)
- 🎯 Matriz global de aceptación: [`docs/guia/MATRIZ_DE_ACEPTACION_GLOBAL.md`](docs/guia/MATRIZ_DE_ACEPTACION_GLOBAL.md)

**Regla de oro:** una fase no se considera terminada porque la IA afirme que lo está. Se cierra únicamente cuando el código, las pruebas, GitHub Actions, los logs y las evidencias verificables cumplen los criterios del archivo de esa fase.
